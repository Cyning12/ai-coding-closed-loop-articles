> **用途**：卷二《技术图谱——让 Agent 先看地图再动手》**文章头图**；视觉与 [`PROMPT_figure_卷一_文章封面_v1_zh.md`](./PROMPT_figure_卷一_文章封面_v1_zh.md) **同系列**（扁平矢量、浅色底、三层结构、蓝绿黄紫分区）。

## 输出规格

| 项 | 建议 |
| --- | --- |
| 画幅 | **16:9** 横版，与卷一封面一致 |
| 风格 | 扁平矢量、浅色背景；**只讲图谱轨**（卷二不展开协作流程全貌，可与卷一封面区分） |
| 语言 | 图中中文标签；顶栏或角标小字「卷二 · 技术图谱」 |

---

## 设计要点（与卷二正文对齐）

| 层 | 卷二要表达什么 |
| --- | --- |
| 上层 | 图谱夹里 **三类物件**（通俗名，非文件名堆砌） |
| 中层 | **Agent 默认读法**：GPS 式「查询子图 + 站牌便签」，不是整本灌 Mermaid |
| 下层 | **CI** 在合并前 **防地图过期**（校对车间），不是替 Agent 读图 |

## 提示词（复制整段）

```text
一张扁平矢量风格的技术信息图，浅色背景，用于博客系列《AI 编程可闭环协作》卷二文章封面。画风与卷一封面同系列：圆角卡片、柔和蓝绿黄紫配色、简洁箭头，不要 3D、不要照片写实、无公司 Logo、无代码截图。

顶栏或左上角小标签：「卷二 · 技术图谱」，副标一行小字「让 Agent 先看地图再动手」。

画面分三层：
1. 上层三块并排（左中右圆角卡片）：
   - 左：标题「人读流程图」，配简化 Mermaid/纸质折页地图图标，副标「主图 · 分册」；
   - 中：标题「机器总图」，配一本厚地图册/网格节点册图标（表示可检索的 graph），副标「导出 · 勿手改」；
   - 右：标题「入口清单」，配公交站牌表/门牌列表图标，副标「从哪进代码」。
2. 中层中央（最大焦点）：圆角矩形主标题「Agent 按图施工」，内写两行副标「GPS 查询子图 + 站牌便签」「默认读法 · 不灌整仓 Mermaid」。从上层三块各有一条弧线箭头指向该中央块。
3. 下层横条（紫色或蓝紫条）：文字「CI · 防地图过期」，配盾牌/校对勾 icon，向上箭头指向中层「Agent 按图施工」。条下可选极小字「合并前校对 · 非替 Agent 读图」。

整体信息密度适中、中文标签清晰可读、留足留白适合平台裁切。不要出现 Harness、任务单、审查签收等卷三才展开的流程名词（本卷只强调图谱与读图）。
```
