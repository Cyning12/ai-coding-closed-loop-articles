## 提示词（复制整段）

```text
一张扁平矢量风格的技术信息图，浅色背景，用于博客系列《AI 编程可闭环协作》卷五文章封面。画风与卷一、卷二、卷三、卷四封面同系列：圆角卡片、柔和蓝绿黄紫配色、简洁箭头，不要 3D、不要照片写实、无公司 Logo、无代码截图、无真实仓库品牌名。

顶栏或左上角小标签：「卷五 · 存量项目怎么落地」，副标一行小字「案例 · 误区 FAQ · 渐进路线 · 先一条链再扩展」。

画面分三层：

1. 上层横向四步（圆角小卡片 + 细箭头串联，从左到右，略呈阶梯上升）：
   - 「阶段 0 · 验得动」+ 盾牌/对勾与清单图标（合并前命令写进任务单）；
   - 「阶段 1 · 一条试点链」+ 单条高亮路径图标（内部 API / 非核心链路）；
   - 「阶段 2 · 图谱检查」+ 门牌号/清单与代码对齐小图标（契约·入口清单）；
   - 「阶段 3 · 默认闭环」+ 循环勾选图标。
   四步下方可选极小字「存量项目 · 一周量级试通 · 勿两周铺满全仓」。

2. 中层中央（最大焦点）：竖向三层堆叠的圆角矩形（自下而上，每层不同浅色：底蓝、中绿、顶淡橙），模拟 §23.1「协作记忆分层」示意图，每层一行主标签 + 一行副标：
   - 底层（最大宽度）：「冷层 · 结构地图」副标「技术图谱 · 主图 + 分册」；
   - 中层：「温层 · 本轮交付轨迹」副标「任务单 · 签收 · 可选跨轮回顾摘要」；
   - 顶层（略窄、虚线边框）：「热层 · 运行时事件记忆」副标「日志 / 监控 · 远期 · 日常不依赖」。
   三层右侧或顶部醒目短标签：「≠ 架构三层」（纠正误读，字号清晰但不过大）。从上层「阶段 1」有一条粗箭头指向冷层，表示先选链再挂地图入口。

3. 下层横条（蓝灰或暖灰条）：左侧简化「老代码库」图标（多层文件夹 + 少量分叉线，表示文档与代码曾分叉）；中间文字「存量仓 · 先验得动再渐进」；右侧两枚小圆角标签：「FAQ 冷/温/热」「诚实边界 · 勿外推」。条下可选极小字「两则周记案例 · BFF 契约串行 · 系列收束」。

整体信息密度适中、中文标签清晰可读、留足留白适合腾讯云/掘金裁切。不要展开 RAG 细节、不要 Harness 帽号链、不要 AB 实验数字；本卷强调 **老项目怎么试、试到哪一步、常见误区与渐进**，不是卷四专题收尾流水线教学全文。
```
